# map/

The map itself: one plain file per node, YAML front matter plus Markdown, readable without
any tool. Node types, ids, links, statuses and provenance are defined in [`../MODEL.md`](../MODEL.md),
which is binding. Everything in this directory is licensed CC BY-SA 4.0 ([`../LICENSE-DATA`](../LICENSE-DATA)).
Nothing here is ever deleted; nodes are superseded and disputes are closed, both at their
permanent address (`CHARTER.md` P4). Empty at founding, 2026-10-04.
